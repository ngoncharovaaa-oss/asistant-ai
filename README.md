# «Двойник» — ИИ-помощник руководителя

Агент для повторяющихся коммуникаций руководителя: готовит черновики от первого лица в его стиле, опирается на базу знаний и трекер, ничего не отправляет без подтверждения и эскалирует чувствительные темы.

Задача «ИИ помощник руководителя», трек «Цифровой аватар», «ИИкузница» 2026.

## Проблема

Руководитель подразделения онлайн-продаж тратит 10–15 часов в неделю на повторяющиеся сообщения: смежники, апдейты команде, типовые вопросы, партнёры. До 60% из них не требуют его присутствия в моменте. При этом часть команды перестаёт получать регулярную коммуникацию от первого лица.

## Что делает

Три сценария вместо одного универсального бота:

- **Черновик** — типовой вопрос: факты из базы знаний и трекера, ответ в стиле руководителя, каждая цифра со ссылкой. Человек проверяет и отправляет.
- **Эскалация** — скидки выше лимита, юридика, пресса, конфликты: агент не отвечает, а передаёт руководителю с причиной и ссылкой на регламент.
- **Дайджест** — раз в неделю сам собирает статусы, риски и решения для команды.

Внутри — цикл из девяти шагов: наблюдение → классификация → план и бюджет → поиск фактов → черновик → самопроверка → подтверждение → отправка → обучение на правках. Шаг подтверждения — инвариант, а не настройка.

## Быстрый старт

Нужен Python 3.12, ключ OpenAI-совместимого провайдера и тестовые аккаунты: ящик «руководителя», ящик «клиента» и Telegram-бот. Настройка — в `10-account-setup-v4.md`, 60–90 минут.

```bash
python -m venv .venv
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Windows: активировать окружение — `.venv\Scripts\activate`. Интерфейс — http://127.0.0.1:8000, демо-запуск — кнопкой «Запустить» на экране «Входящие».

## Настройка

Скопировать `.env.example` в `.env` и заполнить ключ:

```bash
cp .env.example .env
```

| Переменная | Зачем | По умолчанию |
|---|---|---|
| `LLM_BASE_URL` | адрес OpenAI-совместимого API | `https://api.openai.com/v1` |
| `LLM_API_KEY` | ключ провайдера, в репозиторий не попадает | — |
| `LLM_MODEL` | модель для черновиков и самопроверки | `gpt-4o-mini` |
| `RUN_TOKEN_BUDGET` | лимит токенов на один запуск пачки | `60000` |
| `CONFIDENCE_THRESHOLD` | ниже порога — эскалация, а не черновик | `0.75` |
| `DATABASE_URL` | SQLite с обращениями, черновиками и трассировкой | `sqlite:///./data/dvoinik.db` |
| `DEMO_MODE` | `1` — ответы модели из кэша, сеть не нужна | `1` |
| `MAIL_ADAPTER` | почтовый канал: `imap` в живом режиме | `imap` |
| `MESSENGER_ADAPTER` | мессенджер: `telegram` в живом режиме | `telegram` |
| `MAIL_IMAP_HOST`, `MAIL_IMAP_PORT` | входящая почта тестового ящика | `imap.yandex.ru`, `993` |
| `MAIL_SMTP_HOST`, `MAIL_SMTP_PORT` | исходящая почта тестового ящика | `smtp.yandex.ru`, `465` |
| `MAIL_USER`, `MAIL_APP_PASSWORD` | ящик «руководитель» и пароль приложения | — |
| `MAIL_ALLOWED_TO` | единственный получатель — ящик «клиент» | — |
| `TG_BOT_TOKEN` | токен тестового бота из BotFather | — |
| `TG_ALLOWED_CHAT_IDS` | числовые chat_id «клиента» через запятую | — |

Отключить подтверждение отправки нельзя: это жёсткое правило, а не переменная окружения.

## Демо-данные

`data/demo_dataset.json` — 10 синтетических обращений, база знаний, трекер и стилевой профиль. Персональных данных нет, всё помечено как тренировочное. Ожидаемый результат одного запуска: 6 черновиков, 3 эскалации, 1 дайджест, 0 отправок без подтверждения.

## Что реально, а что макет

| Реально в демо | Макет или заглушка |
|---|---|
| Цикл агента, 10 инструментов, трассировка шагов | WhatsApp, MAX и VK — адаптеры за общим интерфейсом, не в демо |
| Живые IMAP/SMTP и Telegram Bot API: письмо и сообщение проходят цикл до отправки | Импорт контактов и склейка дублей — макет |
| Черновики со ссылками, самопроверка, эскалации, allow-list, журнал | Озвучивание и видеоаватар — вне объёма |
| Интерфейс: входящие, карточка, правка, approval, отчёт | Авторизация и роли — один пользователь |
| Дайджест по расписанию, обучение на правках | Хранение в SQLite вместо промышленной СУБД |

## Метрики на демо

- 10 из 10 обращений обработано одним запуском, 67 минут сэкономлено.
- 100% утверждений в черновиках со ссылкой на источник.
- 0 отправок без подтверждения, точность эскалаций 3/3.
- Черновик — 7–12 секунд, прогон пачки — 33 600 токенов и 9,41 ₽.

## Экономика

150 черновиков в месяц: 15 668 ₽ против 75 000 ₽ ручной работы, экономия 59 332 ₽/мес, 104,45 ₽ за черновик, окупаемость с 8 черновиков. Модель и допущения — в `tools/cost_calc.html`.

## Ограничения и этика

Текстовый двойник без клонирования голоса и лица. Отправка только после подтверждения человеком, в сообщении пометка «Подготовлено ИИ, проверено руководителем». PII маскируется в логах, данные не уходят в обучение. Чувствительные темы автоматизации не подлежат.
