# Профили руководителей

Профиль — это настройки, а не код: имя, роль, цели, защищённое время, правила решений, каналы и стиль.
Второй руководитель подключается копированием файла и правкой текста, без изменений в приложении.

## Как добавить

1. Скопируйте `leader2.md` в новый файл, например `ivan.md`.
2. Замените первую строку «Имя — роль» и разделы.
3. Запустите разбор с этим профилем:

```bash
python -m app.cli --data-dir data/kuznitsa --out-dir out/ivan run --profile profiles/ivan.md
python -m app.cli --data-dir data/kuznitsa --out-dir out/ivan --db data/ivan.db serve --port 8001
```

Или выберите профиль на дашборде и нажмите «Пересобрать неделю».

## Что читает движок

- «Цели на квартал» — контекст для сводок.
- «Куда направить освобождённое время» — защищённые блоки календаря.
- «Никогда без подтверждения» — темы, которые всегда уходят на решение руководителя.
- «Можно без подтверждения» — что агент делает сам (рассылки, переносы, передача запросов).
- «Каналы» и «Стиль общения» — каналы доставки и подпись черновиков.

Чувствительные темы (деньги, кадры, обязательства клиентам, письма руководству) зашиты в модель рисков:
если правило профиля их не покрывает, страховка всё равно отправит письмо на подтверждение.
